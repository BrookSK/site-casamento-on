# Imagens do site

Coloque as fotografias do casal **nesta pasta** (`public/assets/img/`) com
exatamente os nomes abaixo. Enquanto um arquivo não existir, o site mostra um
placeholder elegante no lugar — então pode adicionar aos poucos.

## Arquivos esperados

| Arquivo         | Onde aparece              | Enquadramento sugerido                     |
|-----------------|---------------------------|--------------------------------------------|
| `hero.jpg`      | Topo (hero, tela cheia)   | Horizontal/paisagem, casal em destaque     |
| `couple-1.jpg`  | Seção "Nossa história"    | Vertical/retrato (proporção ~3:4)          |
| `gallery-1.jpg` | Galeria (mosaico 2x2)     | Vertical/retrato (recorte 4:5 automático)  |
| `gallery-2.jpg` | Galeria (mosaico 2x2)     | Vertical/retrato (recorte 4:5 automático)  |
| `gallery-3.jpg` | Galeria (mosaico 2x2)     | Vertical/retrato (recorte 4:5 automático)  |
| `gallery-4.jpg` | Galeria (mosaico 2x2)     | Vertical/retrato (recorte 4:5 automático)  |

### Mapeamento atual (fotos do ensaio)

1. Jardim com chafariz (mãos dadas) → `hero`
2. Retrato com buquê (look claro) → `couple-1`
3. Abraço com prédio ao fundo → `gallery-1`
4. Trajes escuros na balaustrada → `gallery-2`
5. Beijo com buquê (trajes escuros) → `gallery-3`
6. Preto e branco (close) → `gallery-4`

## Dicas

- **Formato:** o site aceita automaticamente `.jpg`, `.jpeg`, `.png`, `.webp`
  ou `.avif` — basta manter o **nome-base** da tabela (ex.: `hero`, `couple-1`,
  `gallery-1`). Não precisa converter: se existir `hero.png`, ele será usado.
  Recomendado `.jpg` ou `.webp` para fotos (bom equilíbrio qualidade/tamanho).
- **Peso:** otimize as imagens (idealmente abaixo de ~400 KB cada) para
  carregamento rápido. A `hero.jpg` pode ser maior por ser tela cheia.
- **Resolução sugerida:** `hero.jpg` ~2000px de largura; demais ~1200px.
